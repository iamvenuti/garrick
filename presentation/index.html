The tab you already have open

You already juggle things you can't afford to mix

A client tells you something in confidence. An hour later you're drafting a note for a different client, in the same chat window, with the same assistant that has remembered everything you've said all week. It's convenient, right up until it isn't.

Nothing in that chat knows that one of those two is a wall, not just a change of subject.

The rule everything else serves

One memory, walled use.

Conversations carry their sources and parties. You declare which party pairs must stay apart. The assistant applies those rules before using a conversation for a project. Checks catch some mistakes before a commit.

Slow down here more than anywhere else in the deck. If this doesn't land, nothing after it matters. It's the reason to build this instead of using a folder of chat exports.

Picking it back up

One resume point per thread

Every thread carries a block that says what's done, what the live artifact is, what happens next and who it's waiting on. Closing a session properly (the wrap habit) is what keeps that block true two months later, when you've forgotten everything else about it.

How you actually use it

Built to be spoken to

Names you can say out loud, with no dates or codes buried in them. Say "open Acme, pricing" and it tells you where you left off, in a couple of sentences, not a wall of text. When it mishears a name, it checks against your own list before it guesses.

What it never does alone

You approve what gets shared.

The rules tell the assistant to ask before sending or publishing. Its app permissions control what it can execute. Material it reads is processed by its provider, even though the workspace is on your disk.

This is the slide that answers the fear underneath the whole pitch: that an assistant with this much memory might act on it without asking.

Keeping it honest

A workspace that checks itself

A rule that a machine can check gets a check, added in the same commit as the rule itself. Run it any time and it answers in plain language: a missing resume point, or a project note that links across a declared wall.

$ python3 System/tools/check.py

✓ every zone is its own repository
✓ every open thread has a resume point
⚠ Project note links across a declared wall

Garrick

Illustrative output, not a captured run. The check cannot infer missing walls. Show real checker output in a demo and explain its limits.

What you actually need

Choose an app or a terminal

Desktop route

Claude in Code mode, or Codex in the ChatGPT app. Start with one conversation, a useful brief and a saved next action. Add other tools later.

Terminal route

Claude Code or Codex CLI. Add Obsidian for browsing and cmux for several sessions. No provider desktop app is needed for local CLI work.

Both routes use the same files. Codex remote voice on iPhone adds a paired desktop host, awake and online.

Offer the desktop route first to participants new to Terminal. Add phone access after the first useful session. See docs/extras/phone-access.md for provider requirements.
