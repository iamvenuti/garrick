# {{ZONE}}: open actions

One line per action, Obsidian Tasks style. It opens with the thread it is for, `[[Thread]]: `, or with the project when the project is a single thread; an action that belongs to no thread opens with its party or person instead. The dates go last: `📅` when it is due, `🛫` when it cannot start before, and for something you are waiting on, `#waiting` and `⏳` the day to chase. Tick a line when it is done.

The line below is an example, there to show the shape. It is a task like any other, so the first real action takes it out: whoever writes that action deletes this line in the same edit. `System/tools/check.py` warns while both are here.

## Inbox

- [ ] [[<Thread>]]: <action> 📅 <YYYY-MM-DD>
