# Decision notes

One file per concept added to [`docs/concepts.md`](../concepts.md), named `<issue>-<slug>.md`, with `concept:` and `issue:` in its frontmatter and four bold paragraphs: the concept, what it touches, what was measured, what would show it is wrong.

A pull request names its notes in its description, and a check refuses the merge without them: see [A decision note](../../CONTRIBUTING.md#a-decision-note).
