# Garrick's mark

A cabinet of three compartments behind walls. The narrow one on the left is a book's spine; the blue one is open, the work in hand; the third is closed. It stands for what Garrick does: each party's work kept in its own place, and one thing open at a time.

## Files

| File | Use |
|---|---|
| `garrick-mark.svg` | The primary mark, on cream, white or any light ground. 64 × 64 |
| `garrick-mark-on-navy.svg` | The same on navy or any dark ground |
| `garrick-mark-mono.svg` | One colour, for print, embossing or anywhere colour is not available. Recolour it freely |
| `garrick-mark-favicon.svg` | The small cut, for 32 px and below. Drawn on the 16 px grid, with walls one pixel wide at 16 px. Switches to the dark colours when the browser is in dark mode |
| `garrick-lockup.svg` | The mark beside the wordmark, on light grounds |
| `garrick-lockup-on-navy.svg` | The lockup on dark grounds |
| `garrick-app-icon.svg` | The macOS app icon: the mark on a navy tile, on Apple's icon grid |

Everything is vector. The wordmark is Baskervville SemiBold (ANRT, SIL Open Font License), converted to outlines, so no font is needed to show it.

## Colours

| Role | Hex | Contrast |
|---|---|---|
| Mark blue, on light grounds | `#3D73E0` | 3.5 : 1 on cream |
| Mark blue, on dark grounds | `#8EB1F5` | 6.9 : 1 on navy |
| Text and mark on cream | `#1E2833` (navy) | 11.8 : 1 on cream |
| Text and mark on navy | `#F5F0E6` (card cream) | 13.2 : 1 on navy |
| Cream ground | `#ECE4D3` | |
| Navy ground | `#1E2833` | |

The blue is one colour tuned for each ground: `#3D73E0` loses contrast on navy, so dark grounds take the lighter `#8EB1F5`, as the deck already does. Both blues are for the mark and for graphics; text in blue on cream uses `#2B5CC6`, which reaches 4.8 : 1.

## Rules

- Keep clear space of at least the width of the spine on every side.
- Do not add a gradient, an outline, a shadow or a fourth compartment. Four equal cells read as another company's logo.
- Below 64 px use the small cut. Below 16 px, do not use the mark.
