# Reach

**The concept.** A grant's reach is the zones it may read and the zones it may write, set at the Mac, starting as the zones that are not walled, Knowledge and Garrick's docs.

**What it touches.** It touches Wall, Zone and Grant. A walled zone joins only by name, in Settings, after a notice, with reads and writes as separate choices and the date recorded. No tool an assistant can call changes a reach, so a sentence planted in a record cannot widen it. The wall check does not change.

**What was measured.** Tests: on a fresh install no walled zone is readable or writable, two grants with different reaches each see only their own, a request that names a walled zone outside the reach gets new context required, and a record that asks to widen the reach changes nothing.

**What would show it is wrong.** A walled zone that is readable or writable with no notice, a tool that changes a reach, or a result outside the reach that changes a count, a ranking or a snippet.
